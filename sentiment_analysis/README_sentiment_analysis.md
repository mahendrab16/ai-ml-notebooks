# Sentiment Analysis on Text Comments

## Overview
A beginner-friendly NLP project that classifies text comments using TF-IDF features and Logistic Regression.

## Dataset
The notebook expects `sentiment_data.csv` with:
- `Comment`: input text
- `Sentiment`: target label

**Dataset source and license:** Add the original source and license here. The dataset was not included with the notebook provided for review, so its origin and redistribution permissions have not been verified.

## Workflow
1. Load and validate the CSV.
2. Inspect sentiment-label distribution.
3. Clean text with simple tokenization.
4. Split into training and test sets.
5. Convert text into TF-IDF features.
6. Train a Logistic Regression classifier.
7. Evaluate using accuracy, classification report, and confusion matrix.
8. Predict the label for new comments.
