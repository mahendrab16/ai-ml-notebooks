# Generative Adversarial Network (GAN) – MNIST Image Generation

This notebook demonstrates a basic Generative Adversarial Network (GAN) built with TensorFlow and Keras to generate handwritten-digit-like images using the MNIST dataset.

## Project Overview

A GAN consists of two neural networks: a **Generator**, which creates synthetic images from random noise, and a **Discriminator**, which distinguishes real images from generated images. These networks are trained together so that the Generator gradually learns to produce more realistic samples.

## Notebook Workflow

1. Import TensorFlow, NumPy, Matplotlib, and Keras components.
2. Load the MNIST handwritten digit dataset.
3. Normalize image pixel values to the range `[-1, 1]`.
4. Build the Generator to transform 100-dimensional random noise into a `28 × 28` image.
5. Build the Discriminator to classify images as real or generated.
6. Combine both networks into a GAN and train them using real MNIST images and generated samples.
7. Generate and display 10 sample images from random noise.

## Model Details

- **Dataset:** MNIST handwritten digits
- **Image size:** 28 × 28 pixels
- **Latent noise dimension:** 100
- **Generator output activation:** `tanh`
- **Discriminator output:** sigmoid probability for real/fake classification
- **Training epochs:** 1,000 (as configured in the notebook)
- **Batch size:** 32 (as configured in the notebook)

## Output

The notebook displays 10 images generated by the trained Generator. The quality of the generated digits depends on training duration, model architecture, and training stability.
